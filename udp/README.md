# UDP 视频接收与 FFmpeg 软件解码插件 (udp)

## 插件定位与接口角色
`udp/` 目录实现基于 FFmpeg 的网络视频流接收与多线程解码器，真实插件 ID 为 **`video.ffmpeg`**。该插件实现了系统原生核心接口 `ClientPlugin` 与 `EncodedVideoFactory`（合约：`org.robomaster.client.EncodedVideoFactory/1.0`），角色定义为 `role: "video"`。本插件为原生核心端点，负责在独立工作线程中拉取 UDP HEVC/H.264 码流并提交渲染器。


## 依赖与启用条件
- **外部库依赖**：系统 FFmpeg 运行库（`libavcodec`, `libavutil`, `libswscale`）。
- **启动入口**：通过 `--video-plugin=video.ffmpeg` 加载核心插件；原生核心端点随启动配置加载，更换插件实现需重启客户端。
- **动态调整**：运行期间在“连接与登录”页修改监听地址、端口、编码及来源过滤，再显式应用。允许赛中调试；宿主忙碌或当前赛季没有可用协议适配器时仍会提示不可配置的具体原因。

## 配置字段说明
支持在启动参数及启动配置 Profile 的 `plugins.video` 对象中配置如下字段：

| 字段名 | CLI 选项 | 默认值 | 约束与校验规则 |
| :--- | :--- | :--- | :--- |
| `bind` | `--video-bind` | `"0.0.0.0"` | UDP 监听地址，必须为本机单播 IP 或通配 IP（0.0.0.0 / ::），禁止配置为组播 IP |
| `port` | `--video-port` | `3334` | UDP 监听端口，合法整数范围 1–65535 |
| `codec` | `--video-codec` | `"hevc"` | 视频编码选择：`"hevc"`、`"h264"` 或 `"auto"`（不区分大小写）；自动模式等待参数集确认，默认仍为 HEVC |
| `source_address` | 无独立 CLI | `""` | 可选发送源 IP，必须与监听地址 IP 版本一致且不能为组播/通配地址 |
| `source_port` | 无独立 CLI | `0` | 发送源端口，0–65535（0 表示不限来源端口） |
| `multicast_group`| 无独立 CLI | `""` | 订阅组播组地址，单播接收时留空，有值时必须为有效组播 IP 且与监听地址协议族一致 |

### 最小配置示例 (profile.json)
```json
{
  "schema": 1,
  "options": {
    "video-plugin": "video.ffmpeg",
    "video-bind": "0.0.0.0",
    "video-port": "3334",
    "video-codec": "hevc"
  },
  "plugins": {
    "video": {
      "bind": "0.0.0.0",
      "port": 3334,
      "codec": "hevc"
    }
  }
}
```

编码字节输入由 `EncodedVideoFactory` 的独立端点提供，不是主 UDP 配置中的公开 `input_mode` 开关。

## 使用与状态判断
- **运行验证**：主操作界面显示操作员图传画面，后台统计中的解码帧计数器正常递增且无连续丢包或坏帧报错。
- **参数生效**：运行中修改参数需由宿主配置接口接受。接受后清除旧流画面并推进流代际（`stream_generation`），接收结果与 MQTT 连接独立显示。

传输沿用现有 8 字节大端分片头，压缩数据为 Annex B H.264／HEVC。自动识别是客户端扩展能力，不把 H.264 标成 2026 官方默认编码；RTP、MP4、长度前缀 NAL 等其他封装未在此接口中支持。

链路诊断页显示确认后的编码、尺寸、像素格式、恢复计数以及接收缓冲请求值与系统报告值。缓冲请求固定为 256 KiB，不改变既有策略；系统可能限幅或计入额外开销，因此报告值不等于可用码流容量或排队时延。不支持查询或没有已绑定的套接字时显示未知值，不补成零。

## 断连、缺失与常见报错
- **无视频流**：若 UDP 端口无数据输入，解码工作线程保持等待状态，不会导致主程序挂起或崩溃。
- **常见错误及原因**：
  1. `UDP监听地址须为本机单播IP字面量或0.0.0.0／::`：检查 `bind` 是否误填为组播地址；
  2. `请选择HEVC、H.264或自动识别`：`codec` 字段传入了非指定格式字符串；
  3. `发送源与监听地址的IP版本不一致`：混用了 IPv4 与 IPv6 绑定设置。
