# 手册界面插图

本目录用于《技术与操作手册》的程序界面插图。静态图取自当前客户端窗口，动图为连续操作录制后抽帧、缩放和压缩的版本，均不用于推算实时帧率。

| 文件 | 内容 / 取景范围 |
| --- | --- |
| `hud-current.webp` | 主界面、顶部状态、视频与下方信息 |
| `connection-current.webp` | 连接面板的阵营和九类身份选择区域 |
| `settings-current.webp` | 性能、图传、音效与界面设置区域 |
| `shortcuts-current.webp` | 快捷键管理 |
| `status-current.webp` | Tab 机器人状态表 |
| `protocol-current.webp` | 消息与字段视图 |
| `map-2d-current.webp` | 二维大地图 |
| `map-3d-current.webp` | 三维场地区域与视角控件 |
| `map-signal-result-current.webp` | 信号显示结果 |
| `shortcut-navigation-current.gif` | 帮助、状态与快捷键管理的连续导航 |
| `map-signal-current.gif` | 长按、向右滑选与松开标注 |

图中数值用于说明显示和操作，不代表比赛现场记录。身份、设置和三维图采用对应区域裁切，图注与实际内容一致。

运行素材与场地资源的来源限制见 [UI 素材许可](../../../qml/resources/player/SOURCE-ASSET_LICENSES.md)和[场地资源说明](../../../extensions/battlefield-3d/assets/CAD-NOTICE.md)。
