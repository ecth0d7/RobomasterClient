# 窗口与键鼠输入捕获插件 (input)

## 插件定位与接口角色
`input/` 目录提供基于 Qt 窗口系统的用户键盘及相对鼠标位移捕获实现，真实插件 ID 为 **`input.qt`**，实现原生 `ExtensionPlugin` 接口，角色为 `role: "input"`。该插件负责捕获操作手在主窗口的实体按键、鼠标指针锁定及相对位移积分，并将其传递至策略评估层。


## 依赖与启用条件
- **系统依赖**：Qt GUI / Qt Quick 窗口事件子系统。
- **启用入口**：客户端启动参数指定 `--input-plugin=input.qt`（默认值）。本插件在客户端窗口初始化时绑定事件过滤器，随客户端主生命周期运行；更换需重启程序。

## 配置字段说明
输入插件主要参数受本地 UI 偏好及启动参数调控：

| 字段名 | CLI 选项 / 偏好字段 | 默认值 | 约束与说明 |
| :--- | :--- | :--- | :--- |
| `input-plugin` | `--input-plugin` | `input.qt` | 指定输入插件 ID |
| `sensitivity` | UI 偏好 `sensitivity` | `100` | 鼠标灵敏度系数，整数范围 25–200，超出范围拒绝应用并保留原值 |

### 最小配置命令
```bash
./RoboMasterMqttTest --input-plugin=input.qt
```

## 使用与状态判断
- **使用方式**：使用 `Ctrl+Shift+I` 或界面捕获入口，鼠标指针被捕获并锁定为相对位移模式，键盘按键动作转化为标准键位事件流；
- **判断成功**：操作员按键（如 WASD、右键自瞄等）能够在操作策略面板（`OperatorActions`）或 HUD 相应组件上看到高亮响应与触发记录。

捕获时按 H 打开有资格的远程兑换面板，会暂挂捕获；关闭面板后恢复原捕获意图。再次按 `Ctrl+Shift+I` 才是彻底退出。原始键鼠状态不等于服务器已执行动作。

## 停用、异常与安全限制
- **窗口焦点丢失**：当操作员按下 `Alt+Tab` 或呼出系统对话框导致主窗口失去焦点时，插件自动释放鼠标并清空所有按键按下状态，避免因按键粘滞引发载具失控失步。
- **零权限限制**：`input.qt` 只负责纯粹的原始事件捕获，不具有将原始输入直接打包为 MQTT 发送包的权限，所有指令必须经过 `policy.operator` 策略过滤与会话合法性拦截。
