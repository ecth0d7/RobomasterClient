# 英雄吊射副视频流宿主 (extensions/hero-lob-video)

## 插件概述与角色定位
本目录提供 2026 赛季英雄机器人专属的吊射副视频流接入与解码宿主组件。

- **扩展标识**：`hero.lob.video`
- **内部角色**：`hero-video`（对应宿主实现类 `HeroVideoHost`）。
- **编译选项**：由 CMake 选项 `ROBOMASTER_BUILD_HERO_LOB_VIDEO` 控制编译。
- **独立性说明**：本模块为**编译型可选内部宿主组件，不是独立动态发现的 rmplugin 软件包**。它不注册独立的动态库，而是作为视频子系统的特定扩展端点运行。

## 依赖与启用条件
- **依赖项**：依赖外部提供的 `EncodedVideoFactory/1.0` 解码工厂以及客户端核心通信后端 `ClientBackend`。
- **启用条件**：
  - 仅对本端为英雄机器人的连线部署生效（Client ID 必须为 `1` [红方英雄] 或 `101` [蓝方英雄]）。
  - 必须在己方会话认证通过、比赛规则允许（`rulesAllowed` 为真）且主连接就绪时才创建独立解码器。

## 启动入口与生命周期
- **启动入口**：无需独立启动程序。在客户端连接到有效英雄会话且比赛阶段为 4、存活／连接／上场状态有效、收到新鲜部署确认后，宿主创建独立解码端点。宿主在 GUI 线程管理，FFmpeg 解码在工作线程执行。
- **生命周期机制**：
  - 随英雄机器人的连接与规则状态动态启停。
  - 当会话退出、身份变更、规则限制或显式禁用时，解码工作线程将被同步汇合（join），并主动销毁解码器且清空上一阶段残留图像帧。
  - 若系统缺少 `EncodedVideoFactory`，仅本吊射流功能被禁用，主通道的 UDP 视频流、MQTT 通信与 QML 界面完全独立运行，不受任何影响。

## 配置字段与约束
宿主从 Profile 的 `plugins.video.hero_video` 节点读取配置：

| 字段名 | 类型 | 默认值 | 约束与说明 |
| :--- | :--- | :--- | :--- |
| `enabled` | boolean | `true` | 是否启用该英雄吊射副流解码通道 |
| `format` | string | `"annexb"`| 帧格式，限定为明确的 `annexb` 或 `compact` 格式，严禁格式推断（no format sniffing） |

### 传输契约说明
通过 `CustomByteBlock.data` 接收数据，每个数据块最多承载 300 字节，H.264 帧通常跨块重组，接收频率最高为 50Hz。通道严禁臆造串口 CRC 校验、ROS 序列号或任何合成弹道轨迹。

### 最小配置示例 (Profile 片段)
```json
{
  "schema": 1,
  "plugins": {
    "video": {
      "hero_video": {
        "enabled": true,
        "format": "annexb"
      }
    }
  }
}
```

## 使用与验证
- **操作流程**：以英雄机器人身份（ID 1 或 101）登录客户端并接入图传。
- **成功判断**：长按 K 申请部署并收到确认及新视频后，主视口显示部署画面、解码帧计数增加；长按 L 退出后恢复普通 UDP 画面。
- **断连与丢包**：若发生网络丢包或帧序列不连续，端点立即清空旧图像缓存等待新 I 帧，不尝试外推或平滑插值。

## 限制说明
- 严禁非英雄机型调用该端点。
