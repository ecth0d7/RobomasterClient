# 本地阵容与模拟补充元数据 (extensions/shark-local-roster)

## 插件概述与角色定位
本目录提供用于本地模拟与演练环境的界面元数据补充组件。

- **插件 ID**：`shark.local.roster`
- **入口文件**：`qml/SharkRoster.qml`
- **角色定义**：`local-ui-metadata`
- **独立性说明**：本模块为**只读型 QML 界面补充扩展**。它通过本地 HTTP 轮询补充在模拟演练中缺失的阵容、冷却等字段。

## 协议性质与安全声明
> [!IMPORTANT]
> **本插件仅作为本地模拟环境缺失字段的可选本地补充，绝不冒充官方比赛协议，亦不产生任何官方控制指令。**

- 核心的机器人生命值、状态、支持点数、金币消耗、飞镖靶位以及射击步数等依然以官方 MQTT 回传为准。
- 插件通过本地 HTTP 获取的阵容、卡片、防御符、前哨站 RFID 等数据，仅仅用于操作手视图辅助，绝不伪造官方 ACK 回执或源端签名认证。

## 依赖与启用条件
- **依赖项**：必须在本地运行有对应的模拟服务或元数据适配接口。
- **启用条件**：**仅在连接到 loopback（127.0.0.1 / localhost）MQTT 会话时才允许启动**。非本地连接不加载此组件。

## 启动入口与生命周期
- **UI 入口**：由主视图中的可选 Loader 加载，在支持该扩展的 UI 视图中作为图层加载。
- **生命周期机制**：当 MQTT 会话断开或会话重置时，插件立即中止进行中的 HTTP 请求，并彻底清空所有缓存项。若此扩展缺失或本地 HTTP 服务断开，主客户端的核心 MQTT 数据接收与 HUD 图层仍旧正常运行。

## 配置方式
该组件由当前 QML 宿主按本机连接与 2026 规则上下文加载，没有独立的用户 JSON 配置入口。`manifest.json` 的字段是实现说明；修改其中的 endpoint 或 intervalMs 不会覆盖 QML 中的固定实现值。无需另建最小配置文件。

## 使用与状态判断
1. 启动本地模拟服务与 MQTT 会话。
2. 客户端界面加载该扩展包后，按组件实现的轮询节奏获取已提供的补充元数据获取扩展元数据。
3. **成功判定**：界面辅助状态栏呈现对应的阵容列表与演练参数。
4. **异常处理**：若 HTTP 请求超时或返回非 200，组件保持静默并清空补充视图，不抛出阻断弹窗。
