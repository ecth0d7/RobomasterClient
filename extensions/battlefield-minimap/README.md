# 主界面视觉估计图层

`map.visual-estimates` 是独立的可选 QML 显示包，默认随主界面按需加载；没有有效态势快照时不显示视觉标记。构建开关为 `ROBOMASTER_BUILD_MINIMAP_VISION`。不依赖 QtQuick3D，缺少目录时保留基础地图。

先在 `Ctrl+Shift+E` 的“插件管理”中配置并显式启用 YOLO，或加载已授权队友通信配置。接收端可以关闭本机 YOLO。图层只读取宿主已接纳的 `rm.situation.view/1`，不直接接收网络或发送比赛命令。

黄色空心框、虚线误差圈及 `视敌3?`／`视?` 表示视觉估计；原有雷达图标保持原样。悬停查看来源、时间、误差和内部评分。冲突标叉，不把冲突来源平均。仅 `field.2026` 上图，其它系和无地面位置分别统计为“异系”“未定位”。上限 64 锚点、14 标签，省略数量明确显示，原始 TTL 不因刷新延长。

QML/Canvas 复用现有坐标和布局，便于无三维依赖的部署；代价是二维标签容量有限，近似定位仍依赖本车姿态和相机参数，误差圈不是统计精度保证。主界面、三端共享和缺失扩展回退已通过原生验收，录像与参数假设不代表实车精度。

完整说明、实际截图／动图及验收边界见[技术手册](../../docs/TECHNICAL.md#plugin-isolation)。
