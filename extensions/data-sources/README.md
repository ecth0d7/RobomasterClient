# 数据源扩展宿主 (extensions/data-sources)

## 插件概述与角色定位
本目录是客户端数据源注册表与权限隔离核心模块，负责维护比赛官方数据与外部传感器数据源之间的安全边界。

- **接口角色**：内部核心宿主组件（提供 `DataSourceHost`、`SourceRegistry`、`OfficialSourceSnapshot`）。
- **独立性说明**：本目录为**宿主底层库与框架组件，并非可独立运行或由用户随意挂载的外置插件**。它嵌入在客户端生命周期中，提供核心数据流路由与权限投影。

## 依赖与启用条件
- **依赖项**：依赖 Qt 核心框架，与客户端 Telemetry 状态管道紧密集成。
- **启用条件**：随客户端启动默认激活，作为核心基础设施运行，无须也不支持通过插件管理器单独开关。

## 启动入口与运作机制
- **入口点**：客户端启动后自动初始化内部 `SourceRegistry` 实例。
- **生命周期**：与主进程完全同步。实现宿主数据源接口的外部插件向本模块注册其数据源描述符（`Descriptor`）及目的权限集合（`allowed_uses`）。数据只能单向降级流转，严禁非法拓宽用途权限。

## 配置字段与权限模型
本模块主要解析与校验数据源策略映射，严格限制字段使用目的：

| 字段名称 | 类型 | 说明 |
| :--- | :--- | :--- |
| `robot_id` | integer | 当前数据源关联的机器人编号 |
| `can_send` | boolean | 是否允许向外发送数据 |
| `category_permissions`| object | 类别权限映射（包含 `position`、`objective` 等分类） |
| `localAiFields` | array | 允许用于本地 AI 推理的字段列表 |
| `externalAiFields` | array | 允许传输到外部/远程模型推理的字段列表 |
| `shareFields` | array | 允许向组网队友共享的字段列表 |
| `allowed_uses` | array | 目的约束集合，仅限 `localAi`、`externalAi` 等受管权限 |

### 字段约束说明
非官方数据源严禁声明官方标记（如 `player_export_id`），否则数据项校验失败并被立即丢弃。所有注入项的用途权限必须是注册权限的子集，不得在运行时扩权。

### 最小配置说明
由于本模块为内置核心库，无独立的 JSON 配置文件路径，其安全策略继承自客户端主配置及运行期内部安全上下文。

## 使用验证与异常处理
- **验证方式**：当上层模块提交未经验证的时钟映射或超范围字段时，`SourceRegistry` 会在日志中输出警告并拦截注入。
- **异常隔离**：数据源失效时按来源与会话清理视图。原生动态库与主程序同进程，注册表不提供进程级崩溃隔离。

## 限制说明
- 严禁任何组件伪造 `official_player_client` 属性。
- 更多接口规范请参考 [TECHNICAL.md](../../docs/TECHNICAL.md)。
