# 赛季就绪审计

标识 `season.readiness`，可选扩展，默认关闭。

按 `Ctrl+Shift+E`，进入“实验插件”，点击本项“启用插件”。选择参考赛季；检查规则版本、当前会话、编解码器、坐标标定与部署边界。查看 2027 不会切换当前实际线路。

“停用插件”卸载面板与定时器；时间线还停用对应运行模块、清除本机历史。关闭面板只隐藏，本次会话仍保留启用状态。进程退出后不自动恢复。插件缺失时提示加载失败，核心 MQTT、UDP、QML 继续运行。

复用现有 RulesetCatalog/SeasonConfiguration，避免两份赛季配置冲突。只读面板无需进程或动态库，但不能验证物理网络和最终参赛资格。

包清单采用 `rm.optional.feature/1`，用于记录身份、入口与生命周期；当前宿主通过固定 Loader 加载，不做清单校验、任意包发现或沙箱隔离。可用 `ROBOMASTER_BUILD_LAB_EXTENSIONS=OFF` 停止构建时复制这些包；已有构建目录中的旧拷贝需按部署流程移出，选项本身不删除旧文件。

仅 QML/JavaScript，无新增 Python 或本地动态库依赖。

完整技术取舍、2027 资料边界与验收说明见[统一技术手册](../../docs/TECHNICAL.md#laboratory-2027)。
