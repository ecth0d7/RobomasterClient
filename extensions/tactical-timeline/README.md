# 队内战术时间线

标识 `team.tactical-timeline`，可选扩展，默认关闭。

按 `Ctrl+Shift+E`，进入“实验插件”，点击本项“启用插件”。先启动态势协调器，启用本插件。输入观察／防守／集合文字，可选坐标；勾选共享才发送。接收端也须启用，并明确授权 operator.tactical、参考系、sensor 类型与现有 fusion 用途。

“停用插件”卸载面板与定时器；时间线还停用对应运行模块、清除本机历史。关闭面板只隐藏，本次会话仍保留启用状态。进程退出后不自动恢复。插件缺失时提示加载失败，核心 MQTT、UDP、QML 继续运行。

沿用认证观察信封，人工事件独立路由，不进入位置融合、模型依据或机器人指令。64 字、0.5s 创建间隔、5s 有效期、60s 内存历史、128 条上限。二维青色菱形“人”，三维标明人工；断连或到期只保留历史。同一事件不会续期。

包清单采用 `rm.optional.feature/1`，用于记录身份、入口与生命周期；当前宿主通过固定 Loader 加载，不做清单校验、任意包发现或沙箱隔离。可用 `ROBOMASTER_BUILD_LAB_EXTENSIONS=OFF` 停止构建时复制这些包；已有构建目录中的旧拷贝需按部署流程移出，选项本身不删除旧文件。

运行模块为 runtime/journal.py，在既有 Python 协调器内按需加载；未创建额外进程。自定义观察使用 unit=rm.tactical.mark/1，不能解释为官方协议字段。
