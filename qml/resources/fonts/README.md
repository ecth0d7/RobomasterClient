# 随项目分发的字体

English: These font files ship with the editable UI pack. Theme loads relative project paths; the client does not require a system installation of these fonts. See the adjacent license notices.

| 文件 | 实际用途 | 许可 |
|---|---|---|
| NotoSansCJK-Regular.ttc | 中文标签、正文、状态和中文触发事件 | LICENSE-Noto.txt |
| DejaVuSansMono.ttf | 数字读数 | LICENSE-DejaVu.txt |
| DejaVuSansMono-Bold.ttf | 顶部相对方向编号，统一字号／基线 | LICENSE-DejaVu.txt |
| DejaVuSansMono-BoldOblique.ttf | 先前字体方案保留参考 | LICENSE-DejaVu.txt |
| DejaVuSansCondensed.ttf | 键盘两行中的字母、Shift、Ctrl；Book字重 | LICENSE-DejaVu.txt |

DejaVuSansCondensed.ttf 原样复制自本机 `/usr/share/fonts/truetype/dejavu/DejaVuSansCondensed.ttf`，运行时不访问该系统路径。相邻许可允许随项目复制／分发并要求保留版权与许可。Noto沿既有发行包许可保留；没有为官方素材另行杜撰许可。
