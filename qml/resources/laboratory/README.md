# 原创界面资源

`panel-grid.svg` 为本项目原创的低对比网格，只用于工具面板标题区，不覆盖图传。未使用第三方游戏标识、角色或专有图形。随项目源码同许可分发。

`boot-grid.svg`、`boot-aperture.svg` 和 `boot-relief.svg` 是原创开场资源，分别用于底纹、标识外圈和等距构件背景。开场的分幕节奏参考 [dsh-rhine-splash](https://github.com/Respawn-ID/dsh-rhine-splash)，标识、矢量构件及 QML 动画由本项目实现。开场使用真实连接状态，演出进度单独标注；可跳过、关闭或在设置中重播，减少动态效果时直接进入界面。
